SUBSTRATE FACTS (shared by all three shells)

S1. parsed term shape: research goals are SYMBOL-ATOM-headed application
    terms. The parser (main.py:4445-4460 sym/app; parse_statement
    4532-4580; parse_sentence 4590-4610) builds `forall`, `implies`,
    `nosolutions`, `unknowns`, `greater`, `eq`, `plus` as char atoms in
    the research symbol table — NOT constructor labels. ForAllLabel
    (labels.py:1326) exists but the research surface never uses it.
S2. existing rule representation: compiled library rules are label-headed
    terms; a pack `surface:` header swaps ONLY the head-position label
    atom for a research-vocabulary symbol atom at compile time
    (packs.py:151-160; the sole approved mapping is arithmetic's
    ExprEqLabel -> eq, 768ea6f). Taught research rules parse in the same
    symbol language (`(rule (premises ...) (conclusion ...))`,
    main.py _research_parse_rule) — shell-headed terms are EXPRESSIBLE
    as rule premises/conclusions. No shipped pack, primitive, or
    surface mapping carries a rule headed forall/implies/nosolutions
    (verified: no surface entries beyond arithmetic; no such labels).
S3. candidate-selection path: the genuine-partial machinery is
    goal-seeded conclusion matching — research.py:1785
    (RuleGenuinePartialMatch): each rule's CONCLUSION is matched against
    the goal facts; HeadsCompatible (research.py:1489) is the cheap
    pre-reject, and it compares atom heads BY VALUE (M.Compare), so a
    symbol-headed conclusion pattern is head-compatible with B/C goals —
    head compatibility is NOT the blocker. On conclusion match,
    PartialPremiseMatch scores the premises against facts; the record
    lands as an AttemptedRule with AttemptedRuleUnmatched -> the
    "residual: missing <premise> (rule origin <o>)" line (main.py:3098+).
S4. residual representation: count==0 -> graph.last_residuals renders
    ZeroSuccessorResidualLabel as zero-successor-root (label table
    main.py:4732); count>0 -> per-attempt missing-premise lines. Probe A
    shows the exact target format the shells must produce.
S5. proof-checker support: the checker validates GENERIC rewrite
    inferences (pattern-match premises, instantiate replacement —
    Match/Instantiate/PartialPremiseMatch; no connective-specific
    semantics for forall/implies/nosolutions anywhere in proof.py or the
    firing path). The substrate has NO binder discipline and no
    checker-enforced freshness/eigenvariable conditions — stated in
    tree at planner.py:186-190: "the caller owns freshness, because this
    substrate has no binder discipline yet -- an Induction obligation is
    honest only when its k appears nowhere in the surrounding problem.
    Recorded as a term so the gate can check it, not silently assumed."
    (The induction machinery is the in-tree precedent for the pattern:
    side conditions recorded as terms for a gate, NOT validated by the
    proof checker.)

PER SHELL

forall/implies (probe C):
  parsed shape      (forall n (implies (greater n 1) <eq-body>)); n is a
                    symbol-atom argument, not a bound variable in any
                    checker sense (S1).
  rule representation: expressible — a rule with conclusion pattern
                    (forall ?n (implies ?c ?b)) compiles/teaches in the
                    symbol language (S2); variable heads pass
                    HeadsCompatible (S3).
  checker support   NONE for sound closure: closing C soundly is a
                    forall-INTRODUCTION needing the eigenvariable
                    condition (the inner derivation must not depend on
                    ?n); the checker cannot enforce it (S5).
  candidate path    conclusion-vs-goal matching reaches the shell head
                    by value (S3) — a genuine partial match recording
                    the inner eq as the concrete unmatched premise is
                    mechanically reachable, in exactly probe A's
                    residual format.
  residual repr.    today zero-successor-root (S4); after a shell rule,
                    "missing (eq (plus a a) (plus a a)) (rule origin
                    <shell>)".
  inner exposure    YES without claiming the outer goal — PROVIDED the
                    rule is designed not to fire to closure (premise
                    set includes a condition the rewrite calculus
                    cannot discharge; otherwise an UNSOUND closure
                    becomes possible because nothing in the checker
                    would stop it).
  VERDICT:          implementable as candidate/residual exposure
                    (characterization machinery); CHECKER-BLOCKED for
                    sound proof-producing closure.

nosolutions (probe B):
  parsed shape      (nosolutions positive-integers (unknowns a b)
                    <eq-body>) — domain and unknowns as symbol-atom
                    arguments (S1).
  rule representation: expressible, same symbol-language route (S2).
  checker support   NONE for sound closure: closing a no-solutions

                    derive contradiction — negation/RAA semantics); the
                    checker validates rewrites only, with no

  residual repr.    same transition as C (S4).
  inner exposure    YES, same design constraint as C (expose-only,
                    never fire to closure).
  VERDICT:          implementable as candidate/residual exposure;
                    CHECKER-BLOCKED for sound proof-producing closure.
