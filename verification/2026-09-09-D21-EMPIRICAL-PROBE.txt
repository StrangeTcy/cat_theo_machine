class ObligationSkeletonConclusionGoal(M.Edge):
    """The last skeleton entry that carries a goal term; that goal is the conclusion."""

    def __init__(self, skeleton):
        self.result = self._last_goal(skeleton)
        super().__init__(inputs=M.Pair(skeleton, M.EmptyList), results=self.result)

    def _last_goal(self, skeleton):                     # training.py:250
        if M.IdentityCompare(skeleton, M.EmptyList)() is M.truth_value:
            return M.EmptyList
        goal = ObligationSkeletonEntryGoal(M.Head(skeleton)())()   # :253
        rest = self._last_goal(M.Tail(skeleton)())()  # :254
        if M.IdentityCompare(goal, M.EmptyList)() is M.false_value:
            return goal   # :256
        return rest

BEHAVIOUR: it recurses fully to build `rest`, then returns `goal` the moment it
sees a non-empty goal on the way back up. Because the guard is checked INWARD
from the head (after recursing to the tail), the RETURNED GOAL IS THE FIRST
goal-bearing entry in list order — NOT the last. The docstring on line 244
("The last skeleton entry that carries a goal term") is INVERTED vs actual
behaviour. This is the D21 first-not-last defect.

====================================================================
WHY THE CENSUS MISSED IT (Gate D fixture artifact)
====================================================================
The census's in-memory Gate D probe built its "two-entry" skeleton with entry A
carrying M.EmptyList as its GOAL. That left exactly ONE goal-bearing entry, so
_last_goal's first-nonempty could not be distinguished from the last-nonempty —
the selector trivially returned entry B regardless. With a REAL multi-goal
skeleton (E2 has 3 goal-bearing entries), the HEAD-most / FIRST goal-bearing
entry wins. So the census's "conclusion-goal selector is correct" statement was
a fixture artifact, and D21 must be recorded as REPRODUCES (LIVE), not "passes".

IMPLICATION
====================================================================
Because the conclusion goal is taken to be the FIRST goal-bearing entry, an
acceptance cycle that PROVES the initial goal (which is usually the same as the
meaning-structure start fact) can report SUCCESS without ever having proved the
actual conclusion entry. Combined with D22 (per-obligation audit only on the
failure path), this is the D21/D22 per-obligation-acceptance risk. Fix must
(a) select the true last goal-bearing entry and (b) audit EVERY required
obligation on the success path.
