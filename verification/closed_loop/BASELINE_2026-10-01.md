## Persistence localization, not an implemented repair

The saved constructor-registry root record was:

```json
{"id": 1, "name": "AllConstructors"}
```

In [persistence.py](../../persistence.py), `SnapshotCodec._record_for` searches **all namespace aliases** before writing pair/edge/value structure. [runtime.py](../../runtime.py)'s `save_runtime` first synchronizes a namespace containing `AllConstructors`. Naming a mutable state root as if it were fixed vocabulary can replace its contents with the importing process's registry on restore. The observed missing derivation constructors are consistent with that mechanism.

F1 should localize and regression-test this hypothesis. A minimal fix must distinguish fixed singleton names from dynamic state roots; it must not “repair” replay by registering missing constructors or removing the assertion. This document does **not** claim the only root cause has been established or a fix verified.

Two earlier planning premises are stale:

- The current writer **does emit** ordinary character symbols, and its existing character/rule-shape probes passed.
- The loader creates generic `Edge` objects for saved edge records. This is source-visible, but this pilot requires **semantic constructor/accessor preservation**, not Python subclass identity. A generic edge need not be a blocker when its declared representation works.

### Bounded trace and fresh-process failure

Save this diagnostic as an ordinary file outside Git, e.g. `/home/user/.cache/ctm-spec/reproduce.py`. The `__main__` guard is essential: persistence uses spawned workers, and stdin-only scripts cannot be imported by spawn. The recipe uses no externally supplied plan, no monkeypatch, and no constructor-restoration fallback.

```python
import sys
from cat_theo_machine import labels as L, machine as M, proof as P
from cat_theo_machine.main import _runtime_namespace
from cat_theo_machine.runtime import boot_from_snapshot, make_fresh_runtime, save_runtime
from cat_theo_machine.search import SearchBurst

if __name__ == '__main__':
    mode, path = sys.argv[1:3]
    if mode == 'save':
        r = make_fresh_runtime()
        reg = M.FromContextGetConstructors(r.graph)()
        e = M.EmptyList
        v = M.Pair(M.VarTag, M.Pair(M.Char('x'), e))
        t = M.Atom()
        start = M.Pair(L.PositiveLabel, M.Pair(t, e))
        goal = M.Pair(L.IsRealLabel, M.Pair(M.Pair(L.SqrtLabel, M.Pair(t, e)), e))
        rule1 = P.Rule(M.Pair(L.PositiveLabel, M.Pair(v, e)),
                       M.Pair(L.NonNegativeLabel, M.Pair(v, e)))()
        rule2 = P.Rule(M.Pair(L.NonNegativeLabel, M.Pair(v, e)),
                       M.Pair(L.IsRealLabel, M.Pair(M.Pair(L.SqrtLabel, M.Pair(v, e)), e)))()
        rules = P.CompileRuleChain(M.Pair(rule1, M.Pair(rule2, e)), reg)()
        h = M.Heuristic(L.DFSLabel, L.GoalHeadOrderLabel, M.two,
                        M.one, M.one, M.one)()
        job = M.SearchJob(start, goal, rules, h, L.SearchRunningLabel,
                          M.Pair(M.SearchState(start, e, e, M.two)(), e),
                          M.Zero, M.one, M.one, e, M.Tree(e), M.Tree(e), e, M.one)()
        burst = SearchBurst(r.graph, job, M.nine, reg)()
        job = M.Head(burst)()
        reg = M.Head(M.Tail(burst)())()
        assert M.SearchJobStatus(job)() is L.SearchSuccessLabel
        built = P.BuildDerivation(start, M.SearchJobResultPlan(job)(), reg)()
        d = M.Head(built)()
        reg = M.Head(M.Tail(built)())()
        r.graph._replace_context(constructors=reg)
        r.graph.add_derivation(start, goal, d)
        reg = M.FromContextGetConstructors(r.graph)()
        assert P.IsDerivation(d, reg)() is M.truth_value
        assert M.TermEqual(P.DerivationStart(d, reg)(), start)() is M.truth_value
        assert M.TermEqual(P.DerivationEnd(d, reg)(), goal)() is M.truth_value
        print('PRESAVE_SEMANTIC_READERS_PASS', flush=True)
        save_runtime(r, path, _runtime_namespace())
        print('SAVE_PASS', flush=True)
    else:
        r = boot_from_snapshot(path, _runtime_namespace())
        reg = M.FromContextGetConstructors(r.graph)()
        entries = M.TreeEntries(r.graph.derivations)()
        failed = 0
        seen = 0
        while M.IdentityCompare(entries, M.EmptyList)() is M.false_value:
            entry = M.Head(M.Tail(M.Head(entries)())())()
            start = P.DerivationEntryStart(entry)()
            d = P.DerivationEntryProof(entry)()
            valid = P.IsDerivation(d, reg)() is M.truth_value
            same = M.TermEqual(P.DerivationStart(d, reg)(), start)() is M.truth_value
            print('COLD_ENTRY', seen, 'IS_DERIVATION', valid, 'START_EQUAL', same)
            if not valid or not same:
                failed += 1
            seen += 1
            entries = M.Tail(entries)()
        assert seen != 0 and failed == 0, ('cold semantic-reader failures', failed)
```
